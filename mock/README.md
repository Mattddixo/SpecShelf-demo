# Demo responses

Canned responses for SpecShelf's Try it out. The Pet Store spec's first
server, `https://raw.githubusercontent.com/Mattddixo/SpecShelf-demo/main/mock`,
points here, so `GET /pets` returns the file `mock/pets`. Only that request
has an answer; the other operations return 404 from GitHub.

To try it, a Confluence admin approves `raw.githubusercontent.com` for
Try it out in SpecShelf settings.
